# Superseded Benchmark Specification v0.1

This file is retained only so older links do not break. The original v0.1
organizer draft remains available in the Git history, but it contains broad
experiments and provisional settings that do not define the participant
challenge.

Use these current documents instead:

1. [Scientific Challenge Contract v1.0](scientific_challenge_contract_v1.0.md)
   for the question, team scope and required outputs.
2. [Frozen Benchmark v1.0](frozen_benchmark_v1.0.md) for datasets, checksums,
   training settings, evaluation settings and failure policies.
3. [Evaluation Evidence Guide](evaluation_evidence_guide.md) for metric
   definitions, scientific interpretation and reporting requirements.

The superseded v0.1 text must not be used to change a mandatory comparison or
to infer a participant task.
